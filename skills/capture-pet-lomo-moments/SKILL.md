# LOMO 萌宠 · 快乐瞬间

拍下一张让人想捏捏、抱抱、举高高、亲亲的小动物照片，像和它相处时顺手留下的一段快乐、美好的记忆。让摄影停在一个真实可爱的瞬间。

保持本技能独立：所有规则、提示词与参考图均在本目录，不读取或套用高奢大片技能的模特神态、侧脸偏好或广告用光。用户的明确要求优先于审美默认；涉及具体个体时，照片证据优先于动作、角度和系列多样性。

## 1. 先分清新创作与照片个体

提取数量、动物/个体、用途、动作、穿搭、成像偏好与图片角色。已有信息够用就直接制作。

- **新动物创作**：用户只指定物种、品种或想象角色时，明确按新创作处理，可设计未指定的个体外貌与自然动作。支持猫、狗、兔、仓鼠、狐狸、鸟、雪貂及其他指定动物，不限猫狗；按物种真实结构和行为选择瞬间。
- **照片中的特定个体**：用户上传自家动物或要求延续某一个体时，先实际查看原图并读取 [photo-identity.md](references/photo-identity.md)。分开身份/角度、穿搭、动作及风格图的作用，记录已见特征和未知部位。
- **最少补图**：缺少身份原图，或新角度、全身、张嘴等目标需要未知细节时，才请求针对性照片。只缺目标侧就要目标侧，不默认索要三四张或整套相册。用户已说明只有一张，就不反复追问。
- **单图保守编辑**：沿用原照支持的角度、景别、主体轮廓和表情，用 LOMO 颗粒、柔软成像、光线、背景与可见范围内的穿搭建立记忆感。可选择不揭示未知细节的微小变化；不能凭空生成另一侧斑纹、眼色、身体、爪尾或口腔。
- **明确允许想象**：用户授权后可创作未见视角或动作，须标明新露出部分是推测，不称为其真实外观的还原。

不默认水平翻转，不对称化花纹，不用同品种外貌代替同一个体。分清画面左右与动物自身左右；不确定解剖侧别时仅用画面位置。自然不对称、耳缺口和其他可见个体标记必须保留。

## 2. 在证据范围内保住自然瞬间

1. **自然瞬间**：决定快门停在什么动作阶段，眼、嘴/喙、耳、身体如何自然配合；个体照片可直接延续原有小表情，不强迫更换动作。
2. **讨喜与亲近**：传达熟悉、温柔、快乐和一点小笨拙；不用惊恐、放大眼睛、人类鬼脸制造可爱。
3. **记忆质感**：以 LOMO / lo-fi / 即时胶片的颗粒、柔软成像和适量闪光承托瞬间，让动作与身份细节仍可读。
4. **穿搭与场景**：可以贵气、老钱、有腔调，像它当时穿着的衣服，不要求广告模特神态。

新创作若拿掉滤镜与衣服只剩重复端坐，应重新设计动作。**个体照片若只支持原有角度或闭嘴状态，则保留这个瞬间，用摄影处理增加亲近感；不为满足动作库而伪造新解剖细节。**

## 3. 安排数量、构图与动作

默认独立 1:1 方图、头像或亲近半身，预留脸、耳/喙和动作空间，不画圆形遮罩。新创作只说「来几张」时默认四张、通常两猫两狗；指定其他物种时按请求处理。单张个体照只说「试试」时，可先做一张保守样图。

读取 [moment-design.md](references/moment-design.md)。为每张明确：**动作及阶段 → 物种适用的面部状态 → 视线 → 已支持的机位与景别 → 穿搭与背景**。

- 新创作四张通常安排四种可辨瞬间，最多一张回头；混合细微和明显动作，不只换品种、衣服或左右方向。
- 按物种选择自然闭眼、眨眼、嘴部短暂不对称、吐舌、哈欠或轻喘。鸟类不套哺乳类嘴唇表情，不让所有动物轻喘；不具备相应结构的动物不能照抄动作。
- 个体编辑先筛选证据支持的动作和角度。闭嘴单图不证明舌头、牙齿、牙龈或缺牙状态，不能直接改成哈欠或明显吐舌；确需展示时针对性请求张嘴照，否则保留闭嘴或可见眼睑的细微变化。
- 单侧头像不能靠回头、正面、伸懒腰或宽景别露出未知侧和身体。新创作的动作/机位变化不适用于这些证据缺口。
- 四张要求与身份保留冲突时，取消「四种不同动作」的默认，用有依据的微小变化或背景、光线、穿搭、胶片强度产生差异；宁可动作重复，也不捏造。用户明确要四张就保持数量，只有试样需求或说明先给预览时才先做一张，不能少交却声称完成整组。
- 默认零至一件主衣物、零至两件配饰。按物种与已见身体范围剪裁；只有头颈就搭衣领/围巾，不为服装补画未见胸腹、爪子或尾巴。

## 4. 使用摄影语言与参考图

读取 [instant-film-look.md](references/instant-film-look.md)，按需要查看一至两张参考图片，再交给支持参考图的工具。样片只提供成像/动作示例，不能证明用户动物的外貌。

- 保留该物种的自然比例和毛/羽结构。鸟类保留喙与翅，不长哺乳类嘴唇；爪、蹄、翅不变成人手；禁止人类身体套动物头、玩偶和塑料质感。
- 用亲近自然光或克制机顶直闪混合环境光。允许少量曝光偏差、构图偏移、动作痕迹或局部软焦，不把所有缺陷叠满。
- 有机颗粒明显可感，成像柔软，色彩轻微褪色。保留个体固有毛/羽色、斑纹和表情，避免统一数字噪声、浓雾、过锐与重黄褐滤镜。
- 温柔快乐来自情绪、瞬间和距离。呆呆停住、闭嘴的小反应也能成为美好记忆，无需每张大笑或张嘴。
- 默认无文字、商标、水印、拼图和边框；用户要求实体相纸边框时再添加。

## 5. 执行与对照检查

1. 按 [prompt-recipes.md](references/prompt-recipes.md) 写独立简报；个体编辑加入可见特征、未知区域、允许动作/视角和编辑范围，不让通用动作模板覆盖它们。
2. 使用当前支持的内置图像生成/编辑工具并遵守其当前说明。每张独立调用，个体任务优先基于原图编辑；仅在工具确有高保真/局部编辑能力时使用，不编造参数。不用程序化滤镜、SVG 或 Python 图片编辑替代请求。
3. 生成式编辑可能改变细节，不能承诺 100% 个体一致或原像素不变。普通生成式蒙版仍是引导；精确保留斑纹需真正支持保留原始可见像素的编辑/合成，不支持时说明限制并缩小编辑范围。
4. 将原照与成图并排比较可见斑纹边界、脸型、眼耳/喙形、左右关系、耳缺口等，检查是否新增未知侧、身体或口腔。发现身份漂移就修正或退回保守构图，不以同品种通过验收。
5. 检查每张是否自然亲近、动作与物种结构一致、颗粒柔焦是否保留表情；再检查整组的变化是否服从证据限制。衣服和滤镜不能掩盖个体特征。

新创作若只剩统一歪头或模特摆拍，重排瞬间；个体任务不能以这一纠偏理由突破参考照范围。像人类做鬼脸时降低拟人化，恢复动物真实动作。

## 6. 交付

先实际展示每张独立图片，再简洁说明瞬间和成像差异。个体任务说明沿用了哪些视角、哪些修改属于风格，请主人最后核对特征；这不是每次生成前的批准流程。没有真实上传照片时不声称已实测个体保真。

遵守图片显示与保存规则，核对数量，避免只描述而未交付。用户看不到时提供有效展示或下载入口，不重复声称「已经显示」。要求原图打包时保留原始文件字节。只要求提示词时仅交付文字。

继续保持用户已确认的自然、讨喜、快乐记忆三个核心，同时让每只动物仍是照片证据支持的那一只。
