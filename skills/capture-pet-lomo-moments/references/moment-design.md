# 瞬间设计

先判断是新动物还是用户照片中的具体个体，再选动作和快门时点。不要把「抓拍」只写成一个没有可见反应的形容词，也不要为了动作清楚而捏造未知个体特征。

## 可替换的瞬间

下表是新动物的动作库；用于具体个体前，按 `photo-identity.md` 核对视角、可见范围和口部/身体证据。所有动作均需符合物种真实结构。

| 瞬间 | 真实状态 | 适用与证据限制 |
| --- | --- | --- |
| 短暂错愕、停住半秒 | 嘴或喙自然闭合，视线短暂停住，适用物种的耳朵可轻转 | 不必正面；单侧照片就保留该侧，别为了正面补另一半脸 |
| 眨眼到一半 | 自然眼睑运动，嘴放松 | 仅用于具备相应眼睑/行为的物种；可只改已见的一只眼，不新增另一只眼 |
| 嘴部暂时没收好 | 适用哺乳动物的口鼻毛或嘴唇轻微不对称 | 不画人类坏笑；鸟类不用此嘴唇描述；不凭空扭曲下颌 |
| 舌尖忘了收回 | 放松嘴部和一点自然舌尖 | 物种适合且个体口部有依据时才用；闭嘴单图不自动支持 |
| 哈欠到一半 | 自然眯/闭眼，张嘴，姿态放松 | 个体需张嘴证据，不能猜牙齿、牙龈、舌头或缺牙；不变成咆哮 |
| 活动后轻喘 | 物种适用的放松张嘴和舌部状态 | 不让所有动物轻喘；个体需相关口部依据，不把紧张状态当可爱 |
| 被叫到后突然回头 | 身体与头部方向有差，已见毛/羽可有短暂动作痕迹 | 不暴露未记录的另一侧或后背；新创作一组通常最多一次 |
| 好奇凑近观察 | 头略靠近镜头，目光自然，适用动物可嗅闻 | 控制透视，不为前倾扩大未知身体；鸟类保留真实喙形 |
| 伸懒腰后的停顿 | 适用四足动物的爪、肩背与眼睛相互配合 | 个体必须有该身体范围依据；仅头像照不改成全身伸展 |
| 耳朵刚转动/安静歪头 | 兔、猫等可见耳位微变；鸟等可轻微转头观察 | 依据物种与可见结构选择，不能转到未知侧；避免一组统一歪头 |
| 玩累后的呆萌放空 | 原姿态松弛，嘴/喙闭合，目光暂时游离 | 单图可延续已有小表情，不需要编造动作前因或补身体 |

让惊讶保持在自然日常反应范围，情绪轻松亲近，不靠惊恐、紧绷或被吓坏的状态制造戏剧性。动作前因可作为创作设想，不能声称知道用户原照拍摄时实际发生了什么。

## 系列变化与证据优先

- 新创作四张通常四种瞬间，混合细微与明显反应；不固定「某品种永远哈欠、某品种永远回头」。
- 在物种适用前提下再变化视线、机位或景别，不统一歪头、回看或咧嘴。
- 个体编辑只从照片支持的选项中挑选。请求的新动作或新角度将露出未知部位时，只补问需要的那一张照片；用户没有更多就选择同角度、同范围的保守方案。
- 单侧闭嘴照片可以保留闭嘴停顿或不暴露未知细节的眼睑微变，不能硬凑正面、哈欠、伸展、回头四种。
- 明确要四张时可重复有依据的动作，通过光线、背景、可见穿搭和胶片强度变化完成四张；试样需求可先做一张。不要把动作多样性当成身份保留的例外。
- 可爱来自真实小反应和亲近观察距离；延续原有自然表情也能达到记忆感，不必改出更夸张的表情。

## 最小动作简报

新创作：「它正在 [物种适用动作]，快门刚好按在 [阶段]；[可用面部结构的状态]，身体 [方向/松弛程度]；从 [机位与景别] 拍到。」

个体编辑：「沿用身份照的 [视角、已见范围、轮廓与标记]，保留 [已有表情/有证据的微小变化]；不展示 [未知部位]；通过 [光线、柔焦颗粒与穿搭] 表现自然亲近的记忆瞬间。」
