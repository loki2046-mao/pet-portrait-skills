# 照片个体保留：先确认看到了什么

本指南独立适用于本 Skill。创作某种动物与编辑用户家里的某一个体是两种输入任务；后一种不能用「同品种、差不多」替代身份一致。

## 1. 分配图片角色，记录可见证据

先实际查看每张图片，再分别标记「个体身份/角度」「穿搭」「风格/成像」的作用。不要把随包样片的花纹、脸型或身体移植到用户的动物上。多张身份照应属于同一个体；若有明显冲突且归属不明，只问清冲突照片的归属。

为本次编辑写一份简短的可见特征记录：

- 物种及用户提供的品种信息；无法判断的品种不要确定化。
- 当前机位、头与身体方向、画面范围、可见侧；分清「画面左/右」与「动物自身左/右」。无法确定解剖学侧别时只用画面方位和局部位置描述。
- 观察到的轮廓、头脸比例、眼形和可辨认的眼色、鼻/吻/喙形状、耳形及缺口、皮毛/羽毛的颜色、走向、长短、斑纹位置与边界。
- 特别记录左右不对称、异色、局部白毛、可见疤痕和其他个体标记；不要把它们「美化」成对称或标准品种外观。
- 单列未知区域：未见的另一侧、被遮挡的眼睛、后脑、背部、腹部、四肢、尾巴、口腔、牙齿等。只记实际未知的项目，不把低清或强偏色照片中的猜测写成事实。

不从品种标准补齐个体细节，不把一侧花纹镜像到另一侧，不默认水平翻转，不用风格参考填补未知特征。几张照片仍不能证明所有视角；只使用其中实际展示的证据。

## 2. 判断目标是否超出照片

只有新画面确实需要展示未知特征时才补问，且只要最少的相关照片：

| 目标 | 针对性补图 |
| --- | --- |
| 从单侧改成正面或相反侧 | 正面或目标侧的一张清楚照片；按实际缺口选择，不默认两张都要 |
| 从头像改成全身/背面 | 能看见目标身体范围、对应侧斑纹与尾部的照片 |
| 从闭嘴改成哈欠/明显吐舌 | 能看清该个体所需口部细节的张嘴照片；不要根据同品种猜牙齿或缺牙情况 |
| 从被遮挡的面部改成无遮挡 | 该遮挡部位的清楚照片 |

无需一开始索要整套相册，也不因普通光线、背景或衣料调整而机械要求补图。用户已说没有更多照片，就直接走保守方案，不反复追问。

## 3. 只有一张或不能补图时直接制作

沿用原照或足够接近且不暴露未知区域的角度、景别和主体轮廓。保留已见斑纹、比例和各部位关系，围绕它调整背景、光线、服装与成像。方形构图可裁切或延展简单背景，不向外补画没见过的动物身体。

只在已知几何范围内安排衣领、围巾等；只有头颈就做头颈造型，不能为了毛衣而凭空生成胸腹、爪子或尾巴。允许用自然构图或遮挡使未知部位继续不可见，但不能声称已经保留或重建这些部位。

可用不揭示未知特征的微小眼睑变化或原有姿态表现情绪，避免通过大幅转头、张嘴或伸展露出未记录的细节。闭嘴照不能证明牙齿、舌头、牙龈和缺牙状态；未知眼色也不能凭空指定。

若请求的角度无法可靠支持，用一句话说明并继续给出可执行方案，例如：「这张只看得到这一侧，正面花纹无法确认；我先沿用这个角度，用窗光、羊绒围巾和灰调胶片做一张。」不要只停在要求补图。用户明确允许想象时才可扩展，说明新角度或新露出部分是推测创作，不能称为其真实外观的还原。

## 4. 工具选择与真实性边界

尽量基于原图调用当前可用的图像编辑/参考图能力。仅当工具实际提供时使用高保真输入、局部编辑或蒙版；不要编造参数或把提示词中的「保持不变」当成技术锁定。

生成式编辑仍可能改变细节，不能承诺 100% 身份一致、原始像素锁定或完全还原未见部分。若用户要求斑纹等丝毫不变，先核对工具是否真的支持保留原始可见像素、只替换背景/衣物区域的编辑或合成。普通生成式蒙版只是修改引导，不能据此保证蒙版外像素不变。当前工具不支持原像素保留时，明确说明无法保证逐像素不变，并采取最小范围编辑；不要用整图重新生成冒充原始像素保留。

## 5. 生成后对照

把参考图与成图并排查看，逐项比对可见特征记录：花纹边界、左右关系、鼻吻/喙形、眼耳比例、局部缺口与疤痕、被毛/羽毛方向、主体轮廓。检查是否意外露出了未知侧、身体或口腔，或被饰品/滤镜抹掉关键辨识点。允许光照改变表面明暗，不接受固有斑纹位置或个体结构被改写。

发现身份漂移就修正该处或退回更保守的构图，不以「仍像同一品种」验收。交付时简述沿用了什么视角、哪些修改属于风格；请最熟悉它的主人最后核对关键特征。用户核对是成品检查，不是每次生成前的批准门槛。没有真实输入照片时，不声称已经做过个体保真图像测试。
