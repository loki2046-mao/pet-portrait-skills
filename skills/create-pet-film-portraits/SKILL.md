# 有腔调的动物 · 高奢大片

把真实动物拍出高奢时装广告与文艺电影质感。让贵气、慵懒、惬意、忧郁或文艺的情绪，通过神态、光线、构图与衣料成立。

保持本技能独立：只使用本目录中的摄影规则、提示词与参照，不读取 LOMO 抓拍技能，也不自动混入半眨眼、哈欠、吐舌等快乐抓拍目标。用户的明确要求优先于审美默认；涉及具体个体时，先服从照片证据，再安排风格、姿态与系列变化。

## 1. 先分清输入任务

提取动物/个体、数量、用途、情绪、穿搭、视线、景别与图片角色。信息足够就直接制作。

- **新动物创作**：用户仅指定物种、品种或想象角色时，明确按新创作处理，可自主设计未指定的个体外貌。支持猫、狗、兔、仓鼠、狐狸、鸟、雪貂及其他指定动物，按实际物种调整体态和造型；不冒充用户已有的某一个体。
- **照片中的特定个体**：用户上传自家动物，或要求继续保留某只动物的身份时，先实际查看照片并读取 [photo-identity.md](references/photo-identity.md)。分开身份/角度照与风格图，记录已见特征和未知区域。只有身份任务缺图或目标确实超出已有证据时，才请求最少且针对性的补图。
- **单图保守编辑**：用户只有一张或不能补图时，沿用照片支持的角度、景别和主体轮廓，改光线、背景、衣料与胶片；不脑补相反侧花纹、不可见眼色或身体。不能为凑头像半身、侧脸或全身而补画未知部位。简短说明角度限制后继续制作。
- **明确允许想象**：可按用户授权创作未见视角，但标为推测/新创作，不称为该个体真实外观的复原。

不默认左右镜像，不套品种标准补花纹，不把画面左右误称为动物自身左右。照片里的不对称、耳缺口和其他个体标记优先保留；「同品种」不等于「同一只」。

## 2. 确定情绪与可支持的构图

读取 [cinematic-style.md](references/cinematic-style.md)，选择一种主要情绪：

- **贵气、有腔调**：神态自持，衣料讲究，造型与画面克制。
- **慵懒、惬意**：自然松弛，悠闲望向画外，光线和衣物柔软。
- **忧郁、文艺**：安静出神，视线有去处，画外空间和明暗有余韵。
- **冷淡、时髦**：克制神态，眼镜或配饰成为清楚的造型重点。

默认独立 1:1 方图，优先头肩或上胸近景，保留头像裁切空间，不画圆形遮罩。只说「来几张」且没有具体个体要求时默认四张、通常两猫两狗；指定其他动物则按请求安排。

新创作可优先轻微侧转、四分之三侧脸或正侧面，视线在画外、窗外或近处下方；正面和直视也可服务于造型。系列可变动物、穿搭、情绪、角度与景别。**这些是审美默认，不是个体编辑的必选姿态**：身份照仅支持正面就保持正面，仅支持单侧近景就保持该侧与已见范围，不为系列变化揭示未知特征。

高奢感依靠摄影、材质和气质，不靠品牌字样或道具堆砌。

## 3. 保持物种体态与高级材料

- 按该物种的真实头身比例、眼睛、耳/喙、四肢及毛发/羽毛结构设计。鸟类保留喙与翅，不添加哺乳类嘴唇；爪、蹄、翅不变成人手；禁止人类身体套动物头、公仔或塑料质感。
- 默认一件主衣物、零至两件配饰，可选围巾、披肩、针织、眼镜、软帽、耳机、项链或肩带。按体型与可见部位调整；不合物种结构的配饰直接换掉，不硬套猫狗服装。
- 优先羊绒、细羊毛、罗纹针织、厚棉、亚麻、柔软皮革与低调金属，表现纤维、重量、褶皱和细小使用痕迹。
- 依据自然毛/羽色选择燕麦、象牙、炭灰、烟青、深棕或灰绿。保留个体固有颜色和斑纹，不能被调色或衣饰抹去辨识点。
- 配饰有可信接触和受力，不与耳、喙、被毛融合。个体照只有头颈时只在该范围搭围巾或衣领，不为穿毛衣凭空补身体、爪子或尾巴。

## 4. 建立光影、胶片与色彩层次

- 使用大窗侧光、柔和侧逆光与反射补光，先有方向、阴影结构与空间，再加入颗粒和光晕。
- 使用细密可感的电影胶片颗粒、克制镜头柔化、微量亮边柔晕、柔和高光与丰富中间调。
- 暗部轻偏烟青灰、石板灰或灰绿；受光毛/羽与象牙织物保留中性暖色，烟炭深部有密度与细节。
- 保留焦平面的面部结构与材料纹理。朦胧来自光学和空间，不用整幅失焦或平涂灰膜掩盖身份细节。
- 避免浓黄、重棕褐、艳丽青橙、欠曝、HDR 锐化、磨皮和假景深边缘。默认无文字、商标、水印、边框与拼图。

## 5. 使用参照并执行

1. 按任务查看一至两张随包样片作为风格参照；具体个体的身份由用户原照提供。只迁移样片的光线、色彩、颗粒和材质，不移植其脸型、花纹、身体或房间。
2. 按 [prompt-recipes.md](references/prompt-recipes.md) 写独立简报；个体编辑必须加入可见特征、未知区域、允许编辑范围和视角约束。
3. 使用当前支持的内置图像生成/编辑工具，遵守其当前说明。新图逐张生成；个体任务优先基于原照编辑，工具确有高保真/局部编辑能力时才使用。不要编造参数，不把「保持不变」当成技术锁定，也不用 Python 滤镜或 SVG 替代请求。
4. 生成式编辑可能改变细节，不能承诺 100% 身份一致或原像素不变。必须精确保留斑纹时，核对是否存在真正保留原始可见像素的局部编辑/合成；普通生成式蒙版也只是引导，不保证像素不变。不支持时说明限制并缩小编辑范围。
5. 把个体参考与成图并排比对，再检查整组的摄影一致性。发现斑纹、几何或左右关系变化时修正，不以「同品种」通过验收。

## 6. 按大片标准验收与交付

- 个体任务是否保留实际观察到的花纹、面部比例、眼耳/喙形及特有标记？是否擅自露出或补画未知部位？
- 情绪、光影、构图和服装是否共同形成贵气、慵懒或文艺的摄影质感？
- 毛/羽、针织、皮革与金属是否有真实层次，物种结构和配饰是否可信？
- 神态与视线是否自然，且服从原照能够支持的范围？
- 灰调胶片是否有明暗密度，头像裁切、方形比例及独立图片数量是否正确？

先实际展示图片，再简洁说明造型或情绪差异；个体任务说明保留的视角和修改范围，并请主人核对特征。该核对是成品检查，不是额外的生成前批准。遵守图片显示与保存规则；用户看不到时提供有效展示或下载入口，不重复声称「已经显示」。只要求提示词时仅交付文字。没有真实上传照片时不宣称已实测个体保真。
